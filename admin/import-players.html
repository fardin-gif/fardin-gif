Before you run this: it writes directly to your live Firestore (players, publicPlayers, registeredEmails), exactly the way register.html does.
  • Review every row in the preview table below — rows with a warning or error are highlighted.
  • Rows already found in registeredEmails are skipped automatically (won't be double-imported).
  • Uncheck any row you don't want imported (e.g. a duplicate submission, or one with a typo you'd rather fix by hand afterward in admin/manage-players.html).
  • Once you've imported, move or delete this file (or password-protect the /admin/ folder) — it has no login gate of its own, same as your registration rules currently allow.
